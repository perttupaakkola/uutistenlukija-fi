## Top 3 Quick Wins

1. **"uutiskooste tänään"** — matala kilpailu, korkea intent, tiivistelmäsivu voisi rankata nopeasti
2. **"uutiskirje ilmainen"** — Ghost-kirje lanseerattuna tämä voi rankata hyvin
3. **"talous uutiset ilmainen"** — selkeä aukkopaikka maksumuurien takia

Create `/kooste/` sub-page that aggregates daily summaries, optimized for "uutiskooste tänään" type queries.
