# Tweet Templates — Uutistenlukija.fi

## 4 Reusable Templates

### Template 1 — Breaking News (hard news, economy, geopolitics)
```
[FAKTA tai luku] [Miksi tämä merkitsee jotain — 1-2 lausetta.]

Lue lisää: [URL]

#[Kategoria] #Uutiset
```

### Template 2 — Analyysi (expert commentary, politics)
```
[Kiinnostava kysymys]?

[Asiantuntija] sanoo: [Ydinpointti lyhyesti.]

Koko analyysi: [URL]

#[Aihe]
```

### Template 3 — Curiosity Hook (tech, human interest, science, culture)
```
[Yllättävä fakta — mitä?!]

[Konteksti yhdessä lauseessa.]

👉 [URL]

#[Aihe]
```

### Template 4 — Urheilu (results, records)
```
[Tulos] 🏆

[Mikä teki tästä erityisen.]

Kaikki yksityiskohdat: [URL]

#[Laji] #Urheilu
```

---

## Posting Schedule (EET)
- 07:00–08:30 — aamun uutiset
- 11:30–12:30 — lounasaikaan
- 17:00–18:30 — iltapäivä (peak engagement)
- 20:00–21:30 — ilta
