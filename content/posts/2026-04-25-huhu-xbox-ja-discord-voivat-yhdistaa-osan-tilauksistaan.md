Tuore vuoto viittaa siihen, että Xbox saattaa valmistella uutta Game Pass -tilaustasoa yhteistyössä Discordin kanssa. Huhun mukaan niin sanottu Game Passin Starter Edition voitaisiin liittää osaksi Discord Nitro -tilausta. Vuotaneiden tietojen perusteella paketti tarjoaisi pääsyn yli 50 peliin sekä rajallisen määrän pilvipelaamista kuukaudessa, mutta Microsoft ei ole toistaiseksi vahvistanut tietoja.

Saatavilla olevien tietojen mukaan uuteen versioon voisi sisältyä yli 50 peliä. Esimerkeiksi on mainittu muun muassa Stardew Valley, Fallout 4 ja Grounded. Lisäksi vuodon mukaan pakettiin kuuluisi noin 10 tuntia pilvipelaamista kuukaudessa. Sen sijaan yhä epäselvää on, sisältyisikö tilaukseen moninpelaaminen, sillä sitä ei mainita vuotaneissa tiedoissa lainkaan.

## Vuoto viittaa uuteen Starter Edition -tasoon

Vuodon ydin on väite siitä, että Xbox valmistelisi kokonaan uutta Game Pass -tilaustasoa. Huhun mukaan tämä Starter Edition olisi nykyisiä vaihtoehtoja kevyempi kokonaisuus, joka voitaisiin liittää Discordin Nitro-palveluun. Jos tieto pitää paikkansa, kyse olisi näkyvästä muutoksesta siihen, miten Microsoft paketoi pelipalveluaan eri käyttäjäryhmille.

Vuotaneiden tietojen perusteella uusi vaihtoehto olisi tarkoitettu kustannuksiltaan nykyisiä tasoja kevyemmäksi. Samalla sen sisältö näyttäisi olevan rajatumpi kuin laajemmissa Game Pass -tilauksissa. Juuri tästä syystä moninpelituen puuttuminen vuotaneista tiedoista on merkittävä yksityiskohta, vaikka varmuutta asiasta ei vielä ole.

## Discord-yhteistyöstä on jo vihjattu

Huhua tukee osaltaan se, että Xboxin pelijohtaja Asha Sharma vihjasi aiemmin tällä viikolla tulevasta Discord-yhteistyöstä. Tämä ei kuitenkaan sellaisenaan vahvista vuodon yksityiskohtia tai sitä, että kyse olisi juuri Nitro-tilaukseen liitettävästä Game Pass -versiosta.

Aineiston mukaan Microsoft on samalla uudistamassa Game Pass -strategiaansa tavoitteenaan tehdä palvelusta joustavampi ja kustannustehokkaampi. Mahdollinen Starter Edition sopisi tähän linjaan, jos yhtiö haluaa tarjota entistä kevyemmän sisäänpääsyn palveluun.

## Virallista vahvistusta ei vielä ole

Toistaiseksi kaikki keskeiset tiedot perustuvat vuotoon. Microsoft ei ole vahvistanut uuden tilausmallin olemassaoloa, tarkkaa sisältöä eikä mahdollista julkaisuaikataulua. Siksi myös pelivalikoimaa, pilvipelaamisen tuntimääriä ja Nitro-kytköstä on syytä pitää alustavina tietoina.

Varmistettua tällä hetkellä on lähinnä se, että Xbox on vihjannut Discord-yhteistyöstä ja että markkinoilla liikkuu vuoto uudesta Game Pass -tasosta. Se, muuttuuko huhu viralliseksi tuotteeksi, jää nähtäväksi myöhemmin.
