Google on lopettanut Gemini CLI:n ja Gemini Code Assistin kuluttajatason käytön ja siirtää kehittäjiä uuteen Antigravity CLI -työkaluun sekä laajempaan Google Antigravity -kehitysalustaan. Muutos koskee erityisesti yksittäisiä kehittäjiä ja kuluttajatason tilejä, kun taas Gemini Code Assist for GitHub jatkaa yrityskäyttäjille toistaiseksi ennallaan.

## Kehittäjätyökaluja kootaan yhteen

Gemini CLI ja Gemini Code Assist rakennettiin tukemaan ohjelmistokehittäjiä esimerkiksi koodin ymmärtämisessä, virheiden etsimisessä ja työnkulkujen automatisoinnissa. Gemini CLI:n avulla käyttäjät pystyivät muun muassa kyselemään ja muokkaamaan suuria koodikantoja, luomaan sovelluksia kuvista tai PDF-tiedostoista sekä automatisoimaan monimutkaisia tehtäviä terminaalista käsin.

Google perustelee muutosta sillä, että kehittäjien tarpeet ovat muuttuneet. Yhtiön mukaan yksittäinen komentorivillä toimiva agentti ei enää riitä samalla tavalla kuin aiemmin, vaan kehittäjät tarvitsevat useita agentteja, jotka voivat jakaa tehtäviä keskenään ja kommunikoida toistensa kanssa.

Tämän vuoksi Google kertoo keskittävänsä kehityspanoksensa Antigravityyn sen sijaan, että se ylläpitäisi useita rinnakkaisia kehittäjätyökaluja.

## Antigravity ei vielä korvaa kaikkea

Antigravity CLI on Googlen uusi vaihtoehto, joka liittyy Antigravity 2.0 -työpöytäsovellukseen ja jakaa sen kanssa saman arkkitehtuurin. Googlen mukaan uusi työkalu on nopeampi, tukee useita asynkronisia työnkulkuja ja on rakennettu monen agentin käyttöä varten.

Antigravity on yhtiön mukaan agenttilähtöinen kehitysalusta, jossa tekoäly ei toimi vain yksittäisenä avustajana vaan osana laajempaa kehitysympäristöä. Google kuitenkin myöntää, ettei Antigravity CLI tarjoa heti täydellistä vastaavuutta Gemini CLI:n ja Code Assistin ominaisuuksiin. Yhtiön mukaan tärkeimmät ominaisuudet säilyvät.

Nykyiset käyttäjät voivat joutua muuttamaan toimintatapojaan siirtymän aikana. Gemini CLI ja Gemini Code Assist for GitHub suljettiin kuluttajakäytössä 18. kesäkuuta. Gemini Code Assist for GitHub poistuu käytöstä asteittain: alasajo alkoi 18. kesäkuuta, ja täysi sulkeminen on määrä tehdä 17. heinäkuuta.
