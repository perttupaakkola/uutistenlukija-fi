# Spec: "Pähkinänkuoressa" summary box — article template

**Date:** 2026-04-02
**Author:** Monica (research) + Felix (spec)
**For:** Alex (Hugo implementation)
**Priority:** P1 — quick win, high reader value

---

## Problem
Article pages read like flat summaries. Readers don't get fast orientation on *why this matters to them* before committing to reading.

## Solution
A reusable "Pähkinänkuoressa" (In a nutshell) box directly under the lede, with 3 structured bullets.

## Design
```
┌─ Pähkinänkuoressa ──────────────────────┐
│  • Mitä tapahtui: [1 sentence]          │
│  • Ketä tämä koskee: [1 sentence]       │
│  • Mitä muuttuu nyt: [1 sentence]       │
└─────────────────────────────────────────┘
```

## Implementation for Alex

### Hugo template
1. New partial: `layouts/partials/pahkinankuoressa.html`
2. Renders after first paragraph (lede), before rest of article body
3. Pulls from frontmatter field `key_points` (already exists — 3 bullet points)
4. Wraps in styled `<aside class="pahkinankuoressa">` box

### CSS
- Light background (e.g., `#f8f9fa` or brand accent at 5% opacity)
- Left border accent (brand color, 3px)
- Heading: "Pähkinänkuoressa" in small caps or bold
- Compact: ~80-100px height total, readable at mobile widths

### Content model
- `key_points` already exists in frontmatter (3 Finnish bullet points)
- Pipeline rewriter already generates these
- No pipeline changes needed — just template rendering

### Stretch: content_type label
- Show content_type badge above the box: `Uutinen` / `Analyysi` / `Tausta` / `Seuranta`
- Uses existing `content_type` frontmatter field
- Simple CSS badge, same style as homepage labels

## Why this works
- Maps directly to our daily explainer format (what happened → who it affects → what changes)
- Uses data already generated by the pipeline (`key_points`)
- Zero pipeline changes — pure frontend
- Immediate reader utility improvement
- Makes articles feel more like journalism products, less like AI summaries

## Competitive reference
- Yle: "Analyysi" label + consequence-first framing
- Axios: "Why it matters" box
- NRK: "Forklarer" format labels
